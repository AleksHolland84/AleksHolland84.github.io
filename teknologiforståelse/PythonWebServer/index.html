Introduktion

For at sætte en basic-hjemmeside op med Flask og Python, skal du først være sikker på, at du har Python 3 på din computer.

Dete kan du hurtig tjekke, ved at skrive følgende kommando i en kommando prompt eller terminal.

Åben kommandoprompten ved at trykke Windows Key + R, som åbner "Kør" dialog boxen i Windows, og efterfølgende skrive "cmd" - tryk derefter "OK".

C:\Users\user> 
python --version
Output

(c) Microsoft Corporation. Alle rettigheder forbeholdes.

C:\Users\user>python --version

Hvis python ikke er installeret, kan du følge guiden nedenfor.

Installation og opsætning

Installation af Python3 igennem Microsoft Store

Download Python 3 (seneste udgave i skrivende stund er Python 3.14) ved evt. at benytte linket under Ressourcer. Python3 kan også installeres igennem Microsoft Store:

Installation af Python3 med standalone installer for Python 3.14.3

Hvis du vælger at installere Python fra Pythons officelle hjemmeside, skal du huske at tilføje Python til PATH variablen.

Dette gør du som vist på billedet nedenfor, ved at vinge benet af ved tilvalg: Add python.exe to PATH .

Efter installationen af Python, er du nu klar til installere/hente Flask modulet via pip.

Installation af Flask pakken i et virtuelt miljø

Efter installationen af Python, er du nu klar til installere/hente Flask modulet via pip.

pip eller pip3 er et "package-management system" som anvendes i en kommando linje (Command Prompt eller evt. Bash shell) . Pip/pip3 anvendes til at installere og administrere software-pakker skrevet i Python.

Følg eventuelt den officelle guide til at installere Flask: https://flask.palletsprojects.com

For at installere et modul, skal man benytte pip3 install modul_navn.
Erstat modul_navn med navnet på det modul du ønsker at installere.

Virtuel miljøer

Brug et virtuelt miljø til at administrere afhængighederne for dit projekt, både under udvikling og i produktion.

Hvilket problem løser et virtuelt miljø? Jo flere Python-projekter du har, desto større er sandsynligheden for, at du skal arbejde med forskellige versioner af Python-biblioteker – eller endda Python selv. Nyere versioner af biblioteker til ét projekt kan bryde kompatibiliteten i et andet projekt.

Virtuelle miljøer er uafhængige samlinger af Python-biblioteker, ét for hvert projekt. Pakker, der installeres til ét projekt, påvirker ikke andre projekter eller operativsystemets pakker.

Python leveres med modulet venv, som bruges til at oprette virtuelle miljøer.

Opret en projektmappe og en mappe kaldet .venv indeni:

C:\Users\user\Documents> 
mkdir FlaskServer
cd FlaskServer
py -3 -m venv .venv

Aktiverer miljøet

Før du arbejder på dit projekt, skal du aktivere det tilhørende miljø:

C:\Users\user\Documents\FlaskServer> 
.venv\Scripts\activate

Din shell-prompt vil ændre sig, så den viser navnet på det aktiverede miljø.
